EL PROYECTO

Del dato bruto a una lectura ejecutiva

El proyecto simula una necesidad de Estrategia, Business Intelligence o Analítica dentro de una compañía multinacional de seguros de vida.

Excel / CSV → Power Query → MySQL / SQL → Power BI / DAX → Decisiones

HALLAZGOS

Algunos resultados del análisis

Crecimiento del mercado

La prima directa del mercado sintético aumentó 26,50 % entre 2023-T1 y 2025-T4.

Competencia

VidaGlobal mantuvo el liderazgo en 2025-T4, aunque Horizonte redujo la distancia frente al líder.

Cartera

En 2025-T4 las primas crecieron 4,29 % YoY mientras los asegurados vigentes disminuyeron 3,83 %.

METODOLOGÍA

Análisis con trazabilidad

La solución incluye auditoría de calidad, análisis y validación mediante SQL, definición formal de KPIs, modelado dimensional, medidas DAX, dashboard ejecutivo y una etapa final de interpretación y recomendaciones.

Nota metodológica

Los datos y compañías utilizados son 100 % sintéticos. El proyecto tiene fines educativos y de portfolio y no representa el desempeño real del mercado asegurador chileno.
