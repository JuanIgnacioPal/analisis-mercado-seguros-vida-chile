# 📊 Power BI | Mercado Asegurador de Vida — Chile

Esta carpeta contiene los entregables desarrollados en **Power BI** para el análisis del mercado asegurador de vida chileno, desde la validación del modelo dimensional hasta el dashboard ejecutivo final.

---

## 🧩 Modelo analítico

### `modelo_analitico_seguros_vida_chile.pbix`

Archivo utilizado para construir y validar el modelo dimensional del proyecto.

**Incluye:**
- Modelo estrella con tablas de hechos y dimensiones.
- Relaciones y filtros validados.
- Medidas DAX de control.
- Página de validación contra resultados obtenidos en SQL.

---

## 📈 Dashboard ejecutivo

### `dashboard_ejecutivo_seguros_vida_chile.pbix`

Entregable final orientado al **análisis ejecutivo y competitivo del mercado**.

El dashboard está compuesto por cuatro páginas:

| Página | Enfoque |
|---|---|
| 📌 **Resumen Ejecutivo** | KPIs principales y panorama general |
| 🏢 **Mercado y Competencia** | Participación, ranking y posicionamiento |
| ⚙️ **Desempeño Técnico** | Siniestralidad, gastos, margen y solvencia sintética |
| 📦 **Productos y Cartera** | Mix de productos y evolución de asegurados |

---
